# Service de rangement

Service-de-Ranger est un projet destiné à organiser automatiquement les fichiers en les classant dans les répertoires correspondant à leur catégorie.

## Objectif

Simplifier le rangement des fichiers et maintenir une organisation cohérente du système de fichiers.

## Fonctionnement

Le principe annoncé du projet est de :
- identifier les fichiers à traiter ;
- déterminer leur catégorie ;
- les déplacer vers le répertoire correspondant.

Les règles de classement, les catégories prises en charge et les chemins de destination doivent être définis à partir de la configuration et de l'implémentation du projet.
